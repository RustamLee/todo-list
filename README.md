# To-Do List

A simple, responsive task management web application built with HTML, CSS, and Vanilla JavaScript.

The project is developed as a practical web development assignment, focusing on core functionality, clean UI, responsive design, and browser-based data persistence.

## Features

### Task Management
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed

### Filtering & Search
- View all tasks
- Filter active tasks
- Filter completed tasks
- Search tasks by title

### Data Persistence
- Automatically save tasks using LocalStorage
- Restore tasks when reopening the application

### Responsive Design
- Desktop, tablet, and mobile layouts
- CSS Media Queries
- Flexible layout using Flexbox and CSS Grid

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Browser LocalStorage
- Git & GitHub

## Getting Started

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Run `index.html` using Live Server or open it directly in your browser.

No additional dependencies or build tools are required.

## Limitations

- Tasks are stored locally in the browser using LocalStorage.
- Data is not synchronized between devices or browsers.
- No user authentication.
- No backend or remote database.
- Clearing browser storage will remove saved tasks.
